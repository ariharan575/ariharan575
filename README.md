## 🏗️ Featured Project

### 🔗 StockLinker

**StockLinker** is a B2B SaaS platform designed to connect **Shopkeepers, Wholesalers, and Distributors** in one ecosystem.

The platform focuses on making wholesale product discovery and supplier connectivity easier while helping businesses find products and compare available prices.

#### What I'm Building

- 🔎 Product discovery and search
- 🏪 Shopkeeper & Wholesaler workflows
- 📦 Product and category management
- 💰 Wholesale price comparison
- 🔐 Authentication & authorization
- 🛡️ Secure API architecture
- 🗄️ Database-driven backend
- ⚡ Real-time communication capabilities
- 📊 Scalable SaaS-oriented architecture

#### Technology

**Backend:** Java · Spring Boot · Spring Security · Spring Data JPA · Hibernate · REST APIs · WebSocket

**Frontend:** React.js · JavaScript · Tailwind CSS · Bootstrap · Framer Motion

**Database:** MySQL · PostgreSQL · MongoDB

**Security:** JWT · Refresh Tokens · OAuth2 · Google OAuth2 · Firebase Authentication · Role-Based Access Control

StockLinker is my main project where I apply my knowledge of **backend engineering, full-stack development, databases, security, API design, and SaaS architecture** to a real-world product.
